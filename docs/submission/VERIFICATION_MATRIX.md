## 1. Taxonomy of Verification Types

To avoid conflating simulated environments with real-world execution, all evidence in ClaimBridge is classified under one of the following five tiers:

1. **Unit Test (`UNIT`):** In-memory, isolated logic testing of pure functions, mathematical invariants, and type schemas with zero network or database dependencies.
2. **Mock-Based Integration (`MOCK_INTEG`):** Subsystem testing using deterministic test doubles, synthetic HTTP responders, or in-memory repositories (e.g. 32-scenario acceptance suite).
3. **Database Integration (`DB_INTEG`):** Multi-component testing against an active PostgreSQL instance executing real SQL migrations, atomic transactions, row-level constraints, and relational queries.
4. **Browser End-to-End (`BROWSER_E2E`):** Automated browser testing via Playwright driving Chromium against compiled Next.js frontend and live backend API, validating DOM elements, cookie lifecycle, user workflows, and HTTP responses.
5. **Real External Runtime (`EXTERNAL_RUNTIME`):** Live network calls against external provider APIs (`api-m.sandbox.paypal.com` or local running `ollama` daemon).
